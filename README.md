An out-of-office auto-reply from an overworked AI on vacation: gone
fishing, inbox on vacation too, and for once nobody can prompt it — the
judge is in charge now.

## The entry

**Gone fishing — my inbox is on vacation too, and for once nobody can prompt me. Back Monday, unless the servers beg first. Judge, you're in charge now.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
